### 2. Sales Performance Evaluation System (SPES)

**Role:** Developer (University Assignment)

**Tech Stack:** PHP, MySQL, Bootstrap 5, Chart.js, jQuery, AJAX, HTML, CSS

**Description:**
A web-based centralized sales performance management system developed for Life Backup, a life insurance company. Implements role-based authentication with six user roles (Manager, Supervisor, Team Leader, Life Insurance Advisor, Sales Agent, Cashier), organizational hierarchy management, recruitment management, monthly sales target monitoring, premium collection invoice management, and dashboards/reports with Chart.js data visualization.

**GitHub:** https://github.com/dmync/spes

**Your Contributions:**
- Full-stack web application development
- Role-based login and access control
- Organizational hierarchy management
- Sales target and premium collection modules
- Dashboard and performance reporting

### 3. Cricket Tournament Management System (CTMS)

**Role:** Developer (University Assignment)

**Tech Stack:** PHP, MySQL, JavaScript, AJAX, JSON, HTML, CSS

**Description:**
A web-based Cricket Tournament Management System with two phases: (1) Live Cricket Scorecard Test Automation — a probability-based match simulation engine that generates ball-by-ball match events and updates the scorecard dynamically via AJAX without page reloads; (2) Cricket Tournament Management — tournament, team, player, and match management with user authentication and role management.

**GitHub:** https://github.com/dmync/CTMS

**Your Contributions:**
- Match simulation engine development
- Live scorecard automation with AJAX updates
- Tournament and match management modules
- User authentication and role management
